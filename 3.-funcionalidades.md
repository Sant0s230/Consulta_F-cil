# 3. Funcionalidades

## Principais Funcionalidades

**Telas e navegação**

| Tela ou componente         | Finalidade                                                                            |
| -------------------------- | ------------------------------------------------------------------------------------- |
| Página inicial             | Apresentar o sistema e direcionar para “Entrar ou criar conta”                        |
| Entrar / Criar conta       | Acessar com e-mail e senha ou conta Google                                            |
| Minha agenda               | Mostrar lembretes, próxima consulta com botão “Ouvir” e lista de consultas com status |
| Nova consulta / Editar     | Cadastrar ou alterar os dados de uma consulta                                         |
| Avisos                     | Escolher canais e antecedência dos lembretes                                          |
| Painel “Aa Acessibilidade” | Ajustar a experiência de leitura e interação em todas as páginas                      |

**Cadastro e acesso à conta**

A pessoa informa nome, e-mail e senha para criar a conta, ou utiliza a conta Google. Senhas muito comuns são recusadas. O acesso à conta permite manter uma agenda individual, com restrição dos dados às consultas da própria pessoa.



**Cadastro, edição e exclusão de consultas**

O formulário permite registrar profissional, especialidade, data, hora, local e exigências de preparação.&#x20;

Toda consulta nova começa como **agendada**. Seus dados podem ser editados, e a exclusão solicita confirmação para evitar remoções acidentais. Também há confirmação antes de sair da conta.



**Recursos futuros**

Permanecem como evoluções: envio automático por e-mail e SMS, avisos com o site fechado, instalação como PWA, cadastro independente de profissionais, filtros por profissional/especialidade/status, visão em calendário e integração com calendários externos.
