# 9. Funcionamento e regras de negócio

Fluxo principal

1. A pessoa acessa a página inicial e escolhe “Entrar ou criar conta”.
2. Cria uma conta com nome, e-mail e senha ou utiliza a conta Google.
3. Em “Nova consulta”, registra os dados do compromisso. A consulta começa com status **agendada**.
4. Na agenda, acompanha a lista em ordem de data e hora e a próxima consulta em destaque.
5. Quando a consulta entra no prazo de aviso escolhido, recebe o aviso descrito para o uso com o sistema aberto.
6. Após o compromisso, marca a consulta como realizada ou altera seu status para cancelada.

#### Regras

| Regra                 | Definição na fonte                                        |
| --------------------- | --------------------------------------------------------- |
| Status persistidos    | agendada, realizada e cancelada                           |
| Atrasada              | Consulta agendada cuja data é anterior a hoje             |
| Próxima consulta      | Primeira agendada com data igual ou posterior a hoje      |
| Ordenação             | Data e hora                                               |
| Propriedade dos dados | Cada pessoa somente acessa e altera as próprias consultas |
| Exclusão              | Exige confirmação                                         |
| Saída da conta        | Exige confirmação                                         |

**Atrasada** é uma situação visual, não um quarto status persistido. O sistema não conclui nem cancela consultas automaticamente.
