# 13. Aspectos Éticos, de Privacidade e Segurança

**Principais cuidados identificados:**\
**• Coleta mínima de dados:** o sistema coleta apenas os campos estritamente necessários para o\
funcionamento da funcionalidade (nenhum dado de identificação pessoal como CPF ou dados de\
saúde detalhados é solicitado).

\
**• Consentimento:** como o próprio usuário insere voluntariamente as informações sobre suas\
consultas, não há coleta de dados de terceiros sem conhecimento; em uma versão futura com login,\
seria necessário um termo de consentimento explícito.

\
**• Uso de IA:** como a IA foi usada apenas como apoio à prototipação e à documentação (e não para\
processar dados reais de usuários), não há risco direto de viés ou discriminação algorítmica nesta\
fase do projeto. Ainda assim, qualquer sugestão de código ou texto gerada por IA foi revisada\
manualmente antes de ser adotada, para evitar erros ou informações incorretas;



\
**• LGPD:** caso o sistema evolua para uso real com múltiplos usuários, será necessário adequação à\
Lei Geral de Proteção de Dados (Lei nº 13.709/2018), incluindo termo de consentimento, política de\
privacidade, possibilidade de exclusão dos dados pelo titular e, dependendo da interpretação,\
tratamento como dado sensível (relacionado à saúde) exigindo cuidados adicionais.



Cada pessoa somente lê e altera as próprias consultas, por regras aplicadas no banco de dados. O documento também informa recusa de senhas muito comuns, autenticação gerenciada, HTTPS, criptografia e cópias de segurança na infraestrutura. Não fornece políticas de acesso completas, configurações de criptografia ou registros de restauração de backups.
