# 10. Tecnologias e ferramentas escolhidas

| Camada ou finalidade  | Tecnologia                                        | Uso no projeto                           |
| --------------------- | ------------------------------------------------- | ---------------------------------------- |
| Linguagem             | TypeScript 5                                      | Desenvolvimento da aplicação             |
| Interface             | React 19                                          | Construção das telas                     |
| Estrutura e navegação | TanStack Start 1 e TanStack Router                | Organização das páginas e navegação      |
| Dados na interface    | TanStack Query 5                                  | Busca, cache e atualização de dados      |
| Estilos               | Tailwind CSS 4                                    | Aparência e organização responsiva       |
| Construção do site    | Vite 8                                            | Geração da versão do site                |
| Backend e dados       | Lovable Cloud e PostgreSQL                        | Autenticação, perfis e consultas         |
| Testes                | Vitest 5 e Playwright                             | Testes de regras e verificação das telas |
| Recursos do navegador | Web Speech API, Notifications API e Vibration API | Leitura em voz alta, avisos e vibração   |
| Hospedagem            | Lovable                                           | Publicação do site com HTTPS             |

### Arquitetura do sistema

A interface apresenta as páginas e formulários ao usuário. A aplicação processa as ações feitas nessas telas e consulta ou atualiza os dados armazenados no PostgreSQL por meio do Lovable Cloud.

O sistema também pode abrir recursos externos, como Google Agenda e WhatsApp. Nesses casos, o usuário revisa e confirma as ações nos próprios serviços.
