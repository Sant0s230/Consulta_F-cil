# 15. Hospedagem, publicação e código

Site

O  [prototype-pilot-quest.lovable.app](https://prototype-pilot-quest.lovable.app) é registrado aqui como endereço da versão documentada, sem confirmação de disponibilidade ou correspondência com a versão atualmente publicada.

Segundo a fonte, a publicação ocorre pela Lovable, em rede edge, com HTTPS automático. Alterações visuais entram no site após “Publicar/Atualizar”; mudanças no banco entram em vigor imediatamente, conforme descrito no documento. A equipe deve considerar esse comportamento ao planejar alterações de dados e publicação.

#### Código

O código fica no projeto Lovable, com histórico de versões. A conexão ao GitHub é apresentada como possibilidade e próximo passo para manter uma cópia e permitir trabalho no repositório. Não há confirmação de que essa conexão esteja ativa.

#### Domínio e banco

Domínio próprio é uma evolução sugerida, vinculada à compra do endereço e à configuração na plataforma. O banco e a autenticação permanecem no Lovable Cloud na arquitetura descrita. Não foram informados domínio contratado, plano utilizado, custos ou repositório público.
