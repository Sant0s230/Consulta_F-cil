# 14. Banco de dados: PostgreSQL e Lovable Cloud

O Lovable Cloud armazena os dados em PostgreSQL gerenciado e fornece os serviços de autenticação, com criptografia e cópias de segurança descritas na fonte.

| Estrutura    | Dados documentados                                                   |
| ------------ | -------------------------------------------------------------------- |
| profiles     | Nome, e-mail e celular para avisos, canais escolhidos e antecedência |
| consultas    | Profissional, especialidade, data, hora, local, exigências e status  |
| Autenticação | Contas e credenciais sob responsabilidade do serviço de autenticação |
