# 5. Viabilidade e Escopo Inicial

**O que será desenvolvido nesta etapa:**

Um sistema web funcional de CRUD (criar, ler, atualizar e\
excluir) de consultas, com regras de destaque visual para a próxima consulta e para consultas\
atrasadas.

**O que não será desenvolvido neste momento:**

Autenticação de múltiplos usuários, envio automático&#x20;de lembretes, integração com calendário externo e cadastro independente de profissionais.

**Recursos necessários:**&#x20;

Ambiente Python com Flask instalado; nenhum servidor de banco de dados&#x20;externo é necessário, pois o SQLite opera em arquivo local.

**Principais limitações:**&#x20;

Por não haver autenticação, o sistema, na versão atual, é adequado para uso&#x20;individual em um único dispositivo/navegador; o armazenamento em arquivo único (SQLite) também&#x20;limita o uso simultâneo por múltiplos usuários em produção real.

**Resultado mínimo esperado:**&#x20;

Protótipo funcional, executável localmente, capaz de demonstrar o\
cadastro, listagem, edição, exclusão e atualização de status de consultas, com destaque visual da\
próxima consulta e de consultas atrasadas
