# 9. Informações utilizadas pela solução

| Tabela      | Informação                           | Finalidade                                           |
| ----------- | ------------------------------------ | ---------------------------------------------------- |
| `profiles`  | Nome                                 | Identificar o perfil do usuário                      |
| `profiles`  | Telefone e e-mail de aviso           | Configurar formas de contato                         |
| `profiles`  | Preferências de canal e antecedência | Definir os avisos desejados                          |
| `profiles`  | Nome e celular do acompanhante       | Preparar uma mensagem para WhatsApp                  |
| `consultas` | Profissional e especialidade         | Identificar o atendimento                            |
| `consultas` | Data e horário                       | Organizar a agenda                                   |
| `consultas` | Local e exigências                   | Informar onde será a consulta e o que levar ou fazer |
| `consultas` | Status                               | Indicar se está agendada, realizada ou cancelada     |
| `consultas` | Usuário responsável                  | Associar a consulta à conta correta                  |

As consultas são relacionadas à conta que as cadastrou. As regras de acesso do banco de dados devem impedir que um usuário visualize ou altere os dados de outra conta.
