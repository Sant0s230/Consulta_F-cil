# 13. Arquitetura e tecnologias



| Camada               | Localização descrita                           | Responsabilidade                                     |
| -------------------- | ---------------------------------------------- | ---------------------------------------------------- |
| Interface            | Navegador no celular ou computador             | Telas, ajustes de acessibilidade, voz e notificações |
| Aplicação            | Rede edge da Lovable                           | Entrega das páginas e funções do servidor            |
| Dados e autenticação | Lovable Cloud                                  | Contas, perfis, consultas e regras de acesso         |
| Avisos automáticos   | Integração futura de servidor com e-mail e SMS | Lembretes sem depender da abertura do site           |

O conjunto tecnológico é o **React + TanStack Start, TypeScript e Tailwind CSS**. O banco é apresentado como PostgreSQL gerenciado no Lovable Cloud. Essas informações são declarações da fonte.

Na arquitetura atual descrita, o navegador apresenta os dados da pessoa autenticada e executa recursos locais de acessibilidade, voz e notificação. O banco aplica as restrições de acesso. Na evolução proposta, uma rotina de servidor consultará os compromissos e registrará os envios realizados.
