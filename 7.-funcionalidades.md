# 7. Funcionalidades

| Funcionalidade                | Descrição                                                                                                 |
| ----------------------------- | --------------------------------------------------------------------------------------------------------- |
| Criar conta e entrar          | Acesso por e-mail e senha ou por conta Google                                                             |
| Recuperar senha               | Solicitação de link para criar uma nova senha; o recebimento no site publicado ainda precisa ser validado |
| Cadastrar consulta            | Registro de profissional, especialidade, data, horário, local e exigências                                |
| Visualizar agenda             | Exibição das consultas organizadas por data                                                               |
| Destacar próxima consulta     | Apresentação em destaque da consulta futura mais próxima                                                  |
| Alterar consulta              | Edição dos dados de um atendimento cadastrado                                                             |
| Atualizar estado              | Marcação da consulta como agendada, realizada ou cancelada                                                |
| Identificar consulta atrasada | Destaque visual quando a data passou e a consulta continua agendada                                       |
| Ouvir informações             | Leitura em voz alta dos dados da próxima consulta                                                         |
| Google Agenda                 | Abertura do Google Agenda com os dados preenchidos; o usuário confere e salva                             |
| WhatsApp do acompanhante      | Abertura de uma conversa com mensagem preenchida; o usuário decide se envia                               |
| Preferências de avisos        | Armazenamento das opções de aviso e dos dados de contato do usuário                                       |

### Funcionamento e regras de negócio

| Regra               | Descrição                                                                         |
| ------------------- | --------------------------------------------------------------------------------- |
| Estados da consulta | Agendada, realizada ou cancelada                                                  |
| Consulta atrasada   | É identificada visualmente quando continua agendada e sua data já passou          |
| Próxima consulta    | É a consulta agendada mais próxima, com data igual ou posterior à data atual      |
| Alteração de estado | O sistema não marca automaticamente uma consulta como realizada                   |
| Exclusão            | O usuário deve confirmar a exclusão antes de remover uma consulta                 |
| Privacidade         | Cada conta deve acessar e alterar apenas o próprio perfil e as próprias consultas |

### Acessibilidade

O painel de acessibilidade pode ser aberto pelo botão “Aa”. As preferências são salvas no aparelho e aplicadas às telas do sistema.

| Recurso               | Descrição                                                  |
| --------------------- | ---------------------------------------------------------- |
| Aparência             | Opções clara, noturna ou automática                        |
| Tamanho do texto      | Quatro opções de tamanho, com o padrão ampliado            |
| Alto contraste        | Reforço de contraste para facilitar a leitura              |
| Leitura facilitada    | Mais espaçamento entre letras, palavras e linhas           |
| Redução de animações  | Opção para reduzir movimentos na interface                 |
| Leitura em voz alta   | Botão “Ouvir” para ler a próxima consulta                  |
| Foco visível          | Destaque para navegação por teclado                        |
| Pular para o conteúdo | Atalho para chegar diretamente ao conteúdo principal       |
| Confirmações          | Confirmação antes de excluir uma consulta ou sair da conta |



**Cadastro e acesso à conta**

A pessoa informa nome, e-mail e senha para criar a conta, ou utiliza a conta Google. Senhas muito comuns são recusadas. O acesso à conta permite manter uma agenda individual, com restrição dos dados às consultas da própria pessoa.



**Cadastro, edição e exclusão de consultas**

O formulário permite registrar profissional, especialidade, data, hora, local e exigências de preparação.  Toda consulta nova começa como **agendada**. Seus dados podem ser editados, e a exclusão solicita confirmação para evitar remoções acidentais. Também há confirmação antes de sair da conta.
