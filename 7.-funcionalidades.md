# 7. Funcionalidades

| Funcionalidade                | Descrição                                                                           |
| ----------------------------- | ----------------------------------------------------------------------------------- |
| Criar conta e entrar          | Acesso por e-mail e senha ou conta Google                                           |
| Recuperar senha               | Solicitação de link por e-mail para definir uma nova senha                          |
| Cadastrar consulta            | Registro de profissional, especialidade, tipo, data, horário, local e orientações   |
| Visualizar agenda             | Exibição dos compromissos organizados por data                                      |
| Destacar próxima consulta     | Apresentação em destaque da consulta futura mais próxima                            |
| Alterar consulta              | Alteração de informações já cadastradas                                             |
| Atualizar estado              | Marcação manual da consulta como **Agendada**, **Realizada** ou **Cancelada**       |
| Identificar consulta atrasada | Destaque visual quando a data passou e a consulta continua agendada                 |
| Ouvir informações             | Leitura em voz alta dos dados do próximo compromisso                                |
| Google Agenda                 | Abertura do Google Agenda com os dados preenchidos para o usuário conferir e salvar |
| WhatsApp do acompanhante      | Abertura de uma conversa com mensagem preenchida; o usuário decide se envia         |
| Preferências de avisos        | Ajuste das opções de aviso e antecedência disponíveis                               |
| Acessibilidade                | Ajustes de aparência, texto, contraste, leitura e navegação                         |
| Ajuda                         | Instruções passo a passo sobre as funções do sistema                                |

### Funcionamento e regras de negócio

| Acesso à conta                       | Cada usuário deve visualizar e alterar somente os próprios dados                                          |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------- |
| Tipo do compromisso                  | O usuário seleciona consulta, exame ou procedimento                                                       |
| Situação                             | O usuário marca o compromisso como realizado ou cancelado; a data determina se é hoje, futuro ou atrasado |
| Próximo compromisso                  | É o compromisso agendado mais próximo com data igual ou posterior à data atual                            |
| Compromisso atrasado                 | É aquele cuja data passou e que continua com situação agendada                                            |
| Alteração automática                 | O sistema não marca automaticamente o compromisso como realizado                                          |
| Exclusão                             | É solicitada confirmação antes de excluir um compromisso                                                  |
| Google Agenda                        | O usuário revisa o evento preenchido e decide se salva                                                    |
| WhatsApp                             | A mensagem é preparada, mas não é enviada automaticamente                                                 |
| Avisos no aparelho                   | Aparecem quando o ConsultaFácil está aberto                                                               |
| Preferências de acessibilidade       | Ficam salvas no aparelho                                                                                  |
| Preferências de aviso e acompanhante | Ficam associadas à conta do usuário                                                                       |

### Acessibilidade

O painel de acessibilidade acessibilidade ficam em **Configurações**, acessadas pelo ícone de engrenagem. O botão “Aa” usado em versões anteriores foi removido.

| Recurso               | Descrição                                                  |
| --------------------- | ---------------------------------------------------------- |
| Aparência             | Opções clara, noturna ou automática                        |
| Tamanho do texto      | Quatro opções de tamanho, com o padrão ampliado            |
| Alto contraste        | Reforço de contraste para facilitar a leitura              |
| Leitura facilitada    | Mais espaçamento entre letras, palavras e linhas           |
| Redução de animações  | Opção para reduzir movimentos na interface                 |
| Leitura em voz alta   | Botão “Ouvir” para ler a próxima consulta                  |
| Foco visível          | Destaque para navegação por teclado                        |
| Pular para o conteúdo | Atalho para chegar diretamente ao conteúdo principal       |
| Confirmações          | Confirmação antes de excluir uma consulta ou sair da conta |
