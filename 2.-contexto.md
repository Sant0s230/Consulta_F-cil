# 2. Contexto

## Área de Aplicação

O projeto se enquadra principalmente na área de Saúde, por lidar diretamente com o\
acompanhamento de consultas médicas, mas sua aplicação se estende também à organização\
pessoal e gestão de compromissos profissionais em geral (jurídico, terapêutico, odontológico), o\
que o aproxima também das áreas de Comércio e Serviços.

Perfil e necessidades:
----------------------

O sistema foi projetado para ser utilizado por pessoas com diferentes níveis de\
familiaridade com tecnologia. Por isso, a interface prioriza simplicidade visual (Bootstrap, layout\
responsivo) e fluxos diretos de cadastro, edição e exclusão, sem exigir conhecimento técnico do\
usuário final. Não há, na versão atual, adaptações específicas de acessibilidade (leitores de tela, alto\
contraste), o que é apontado como uma evolução futura necessária para atender usuários com\
deficiência visual, por exemplo.

**Acesso e uso:** Acesso individual por celular, principalmente pelo uso de pop-ups que será uma forma de avisar o usuário sobre possiveís alertas. Será uma aplicação gratuita e de cadastro simples.
